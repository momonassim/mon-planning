# Mon Planning

Planning 5x8 (cycle de 35 jours, remonte), en app web installable sur l'écran d'accueil.
Lien : https://momonassim.github.io/mon-planning/

iPhone : ouvrir le lien dans Safari → Partager → « Sur l'écran d'accueil ».
Android : ouvrir le lien dans Chrome → ⋮ → « Installer l'application ».

Toutes les données restent sur le téléphone de chacun.
